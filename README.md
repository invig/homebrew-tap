# invig/tap

Homebrew tap for [Expanse](https://github.com/invig/expanse), your Mac on an infinite canvas.

```bash
brew install --cask invig/tap/expanse
```

Expanse keeps itself up to date from its GitHub releases, so `brew upgrade` leaves it alone
unless you ask (`brew upgrade --cask --greedy expanse`). The cask here is updated with every
release.
